## Summary of obligations and flags

- **python-bidi (LGPL-3.0)**: a core dependency, used unmodified as a separate library (imported, not vendored or changed). This is compatible with MIT distribution; if you ship a frozen bundle (PyInstaller), keep it replaceable and include the LGPL text.
- **MPL-2.0 (certifi, tqdm, orjson, hypothesis, pathspec)**: file-level weak copyleft, used unmodified. No obligation beyond keeping the notices.
- **NVIDIA CUDA runtime libraries (proprietary, redistributable EULA)**: on Linux, the default PyPI `torch` wheel depends on `nvidia-*` / `cuda-toolkit` packages. They are pulled only by the optional extras that need torch (`ocr`, `lama`, `manga`, `offline-mt`), never by the core, `rapid` or `gui`. For a fully open-source install, install the CPU build of torch first: `pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu`, then `pip install -e ".[ocr,lama,gui]"`. Windows and macOS PyPI wheels do not include them.
- **comic-text-detector weights (GPL-3.0)**: opt-in only (`--detector ctd`), never downloaded by default. The ONNX file is downloaded into the user's cache, not distributed by MangaAR.
- **OPUS-MT Marian models (CC-BY-4.0)**: offline translation (`models download local-mt`). Attribution to the Helsinki-NLP / OPUS-MT project is required when you publish translations made with them.
- **NLLB (CC-BY-NC-4.0)**: deliberately **not used** (non-commercial).
- **Fonts**: all bundled fonts are SIL OFL-1.1; licence texts ship in `src/manga_ar/assets/fonts/licenses/`.
